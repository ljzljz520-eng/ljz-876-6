# 🤖 编程闯关乐园 KidCode Quest

少儿编程闯关题库系统。孩子通过**拖拽积木**完成「顺序逻辑 → 循环 → 条件判断 → 小项目挑战」四章共 **10 个关卡**，
系统按积木数量给出 **1～3 星评价**与**个性化鼓励反馈**；家长只看学习进度（看不到标准答案）；
老师可以为班级**布置关卡**，并从数据上看出**哪些概念把学生卡住了**。

## ✨ 功能一览

### 🧒 学生端
- 四章 10 关：顺序（3 关）、循环（3 关）、条件（2 关）、综合小项目（2 关）
- 拖拽式（也支持纯点击，触屏友好）积木编程：`向前走 / 转弯（可切换左右）/ 重复 N 次 / 如果…否则…`
- 网格机器人**逐步动画执行**，撞墙抖动、沿途收集星星、到达旗帜立即判胜
- 服务端权威判题 → 按使用积木数评 3/2/1 星，弹出随机鼓励语与针对性引导（不给答案）
- 关卡内"小提示"折叠区，只提示思路
- 可看到老师布置的关卡（📋 角标）

### 👪 家长端
- 通过孩子用户名关联多个孩子
- 查看：通关数、累计星星、练习次数、成功率、每个**概念的掌握度百分比**
- 关卡明细表（状态/最佳星级/尝试次数/最近练习）
- 🔒 隐私设计：后端与界面**都不返回题目参考解或孩子程序**，只有进度数据

### 🧑‍🏫 老师端
- 创建班级，生成**邀请码**（学生注册时输入即可入班）
- 从题库勾选关卡（可设截止时间）**布置给全班**
- 学情概览：
  - 按概念（顺序/循环/条件/项目）聚合**失败尝试次数、通关人次、平均星级**，自动标记"需重点讲解/有点卡/较顺畅"
  - 每个已布置关卡的完成人数、平均星、总尝试，以及**主要卡点原因**（撞到墙/漏收星星/没走到终点…）
- 学生明细：逐关进度色块（绿通关/黄尝试中/红卡住/灰未开始），**尝试 ≥3 次未通关自动标红预警**

## 🗂️ 技术栈
- 前端：React 18 + Vite（无额外 UI 库，纯 CSS 童趣界面）
- 后端：Node.js + Express + better-sqlite3（单文件数据库，零外部依赖）
- 鉴权：JWT + bcryptjs；基于角色（student / parent / teacher）的接口权限
- 判题：前后端共享同一仿真引擎 `engine.js`（前端播动画、后端做权威判定）

## 🚀 快速开始

```bash
npm run install:all     # 安装根目录、server、client 依赖
npm run seed            # 写入演示数据（老师/班级/学生/提交记录）
npm run dev             # 同时启动 API(4000) 与前端(5173)
```

打开 http://localhost:5173 ，演示账号（密码均为 `1234`）：

| 角色 | 用户名 | 说明 |
| --- | --- | --- |
| 老师 | `teacher` | 已创建班级"三年级编程一班"，邀请码 `KID2026` |
| 家长 | `mama` | 已关联小明、小红 |
| 学生 | `xiaoming` / `xiaohong` / `xiaogang` | 进度各不相同 |

生产构建：`npm run build`，产物在 `client/dist`。

## 📁 目录结构
```
server/
  src/engine.js     # 积木程序仿真引擎（前后端共享，client/src 下有同步副本）
  src/levels.js     # 10 个关卡的世界数据（只含地图，不含答案）
  src/db.js         # SQLite 表结构
  src/auth.js       # JWT / 角色中间件
  src/app.js        # Express API
  src/seed.js       # 演示数据
  verify-levels.mjs # 关卡参考解自动校验（全部达成 3 星，错误解不能通过）
client/
  src/pages/        # 登录 / 关卡地图 / 闯关 / 家长 / 老师 / 班级详情
  src/components/   # 积木箱 / 积木编辑器 / 网格动画
```

## 🔐 安全说明
- 所有提交都在**服务端重新仿真判题**，前端结果仅用于动画
- 提交时校验：积木类型必须在该关 `allowed` 白名单内、循环次数 1～60、条件枚举合法
- 关卡接口只下发地图/任务/思路提示/星级阈值，**题库中不存储参考解，接口也从不返回程序内容**
- 家长 Token 无法访问学生提交接口、老师接口（角色中间件 403）
