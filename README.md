# 星光编程闯关：少儿编程闯关题库

一个面向少儿的编程闯关 Web 应用。孩子通过拖拽积木完成顺序、转弯、循环、条件判断与小项目挑战；系统在服务端模拟运行并给出 1–3 星和鼓励反馈。家长只查看学习进度，不直接看到标准答案；老师可以创建班级、布置关卡，并分析学生在哪些概念上反复卡住。

## 角色与核心功能

### 孩子 / 学生
- 可视化积木拖拽，支持循环和条件积木嵌套。
- 机器人网格实时动画：移动、转向、撞墙、收集星星、到达能量站。
- 9 个递进关卡：
  1. 顺序指令
  2. 方向与转弯
  3. 基础循环
  4. 循环收集
  5. 嵌套循环
  6. 条件判断 + 直到循环（随机星星布局）
  7. 道路/墙壁条件迷宫
  8. 循环小项目
  9. 综合挑战
- 服务端根据程序运行结果评分：
  - 1 星：完成目标；
  - 2 星：不超过关卡建议步数；
  - 3 星：步数和积木数量都足够简洁，并使用目标概念。
- 失败时显示温和反馈和分类提示，不提供可复制的标准答案。
- 使用老师给出的班级码加入班级。

### 家长
- 使用孩子的家庭连接码绑定孩子。
- 查看：
  - 已完成关卡和最佳星级；
  - 概念掌握进度；
  - 练习次数、最近练习时间；
  - 作业完成状态。
- 家长端明确不显示：
  - 标准答案；
  - 孩子提交的积木程序；
  - 失败答案；
  - 关卡可运行积木结构等解题数据。
- 家长账号不能进入孩子闯关页或提交接口。

### 老师
- 创建班级并生成 6 位班级码。
- 按关卡给班级布置作业，可设置建议完成日期和备注。
- 查看班级学生名单与作业完成情况。
- 自动聚合“卡住的概念”：
  - 尝试次数、失败率；
  - 撞墙、遗漏星星、循环无法结束、空收集等错误类型；
  - 连续多次失败但尚未通过的学生名单；
  - 对应教学建议。
- 老师看到的是教学分析，不向家长侧暴露标准程序。

## 技术栈

- Python 3.11+
- Flask 3
- SQLite（标准库 `sqlite3`，无需外部数据库）
- Jinja2 模板
- 原生 HTML/CSS/JavaScript
  - HTML5 Drag & Drop 嵌套积木编辑器
  - 前端只做动画，真正判分在服务端执行

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app run.py init-db
python run.py
```

打开：<http://127.0.0.1:5000/>

也可以直接运行：

```bash
python run.py
```

应用在启动时也会自动初始化 SQLite 表结构。默认数据库路径：

```text
instance/coding_quest.sqlite3
```

可通过环境变量覆盖：

```bash
DATABASE_PATH=/path/to/app.sqlite3 SECRET_KEY=change-me python run.py
```

## 测试

```bash
pytest -q
```

测试覆盖：

- 每个关卡均存在可通关解法；
- 循环、嵌套循环、条件判断和直到循环被正确识别；
- 三星评分、撞墙、越界、循环不终止等分类；
- 注册登录、关卡解锁、作业解锁；
- 孩子提交记录；
- 家长绑定与隐私边界；
- 老师布置作业、概念卡点分析；
- 孩子、家长、老师三种角色的访问控制。

## 目录结构

```text
app/
  __init__.py          # Flask 应用工厂
  auth.py              # 登录态、密码哈希、角色校验
  db.py                # SQLite 连接和表结构
  levels.py            # 关卡定义与服务端模拟器/评分器
  routes_auth.py       # 注册、登录、退出
  routes_child.py      # 孩子闯关和运行 API
  routes_parent.py     # 家长进度页
  routes_teacher.py    # 班级、作业和概念卡点分析
  templates/           # Jinja2 页面
  static/
    css/styles.css     # 响应式儿童友好界面
    js/play.js         # 拖拽编辑器与运行动画
tests/                 # pytest 自动化测试
run.py                 # 本地启动入口
requirements.txt
```

## 安全与教育产品设计说明

- 密码使用 Werkzeug PBKDF2 哈希保存，不存明文。
- 关键判定在服务端完成，前端不能自行修改星级。
- 系统不保存孩子完整积木程序，只保存结果、步数、积木数、使用概念和失败分类，降低答案扩散风险。
- 家长接口只能访问自己绑定的孩子。
- 老师只能查看自己班级的学生和作业。
- 作业和关卡数据使用数据库外键及角色装饰器隔离。

> 当前内置登录适合教学原型/内网使用。若部署到公网，应配置 HTTPS、固定 `SECRET_KEY`、生产 WSGI（如 gunicorn/uwsgi）、会话 Cookie 安全选项和速率限制。
